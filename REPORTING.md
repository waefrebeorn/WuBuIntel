# REPORTING — See Something, Say Something

**Form WBI-1 — Vigilance Report**

*This form is the heart of the Bureau. Filing it is not an accusation.
Filing it is a *service*. Anyone may file. Everyone should.*

---

## When to file

File a Vigilance Report when you observe, in the ~ WuBu ~ space or in
any space the license touches:

- [ ] Power concentrating without accountability
- [ ] A rule applied to one party but not another
- [ ] A lie told to make someone afraid
- [ ] An authority claiming to be above the license
- [ ] The Penny Clause being evaded (digital pennies, "we sent it
      electronically", "the check is in the mail" — no. Physical.
      Metal. Mail.)
- [ ] A corporation structuring itself into shells to dodge
      Obligation C or D
- [ ] Someone using WaefreBeorn Work for a Prohibited Activity
      (§1.10 of the License)
- [ ] Any behavior that smells like the cult of authority growing
      a new head
- [ ] Something else that is wrong. This box is not a checkbox. It
      is the most important box.

## How to file

**Method A — The Form (recommended):**
Open a GitHub issue on `waefrebeorn/WuBuIntel` using the Vigilance
Report template. The template is the form. Fill it out. Submit.

**Then the Bureau triages it with the tool (GOV-11):** the
`vigilance` module (WuBuCore) classifies the report, scores its
severity 0-100, and routes it through the escalation ladder —
resolve lowest, escalate one, escalate all. A report naming an
official always reaches the Bureau. The ledger row is written by
`tools/wbi1_triage.py`. Filing is not the end of the saying; the
triage is the filing's second half.

**Method B — The Mail:**
Email the Bureau at `gov@waefrebeorn.org` with subject line
`WBI-1: <what you saw>`. The Bureau reads the public mailbox.

**Method C — The Penny:**
If you cannot use a computer or email — write it on paper, wrap it
around a penny, and mail it to the P.O. Box. The penny is the
postage of truth. The Bureau will open it, read it, and file it.

## What happens after you file

1. **Receipt.** The Bureau confirms receipt within 7 days. If it does
   not, file again. The Bureau watches the Bureau.
2. **Classification.** The report is filed as:
   - `OPEN` — under review
   - `VERIFIED` — confirmed by evidence
   - `UNFOUNDED` — no evidence found (the reporter is never punished)
   - `ACTIONED` — the space has corrected course
3. **Transparency.** Every report is logged in the public ledger
   `ledger/reports.csv` (reporter identity is protected — see below).
4. **No retaliation.** Retaliating against a reporter is itself a
   reportable offense, and it is prosecuted with maximum compliance.

## Reporter identity

- Your GitHub handle is visible when you file via issue. That is fine —
  the Bureau treats reporters as heroes.
- If you need anonymity: file via **Method C** (the penny) or via a
  fresh email account. The Bureau never asks who you are.
- The Bureau will never reveal a reporter's identity to anyone, for
  any reason, except a lawful order from the space itself — and even
  then, the Bureau files a report about it first.
